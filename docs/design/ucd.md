# UCD：质量保障旅程与信贷工作台

状态：待确认设计；2026-10-31。本文件与 SVG 均为设计产物，不是运行页面。

## 使用者与核心任务

| 使用者 | 核心任务 | 完成位置 |
|---|---|---|
| 演示者 / 质量负责人 | 理解保障范围，沿旅程找到证据 | Portal |
| 信贷分析体验者 | 选择合成案例，运行真实 Agent，理解辅助建议 | 信贷工作台 |
| 开发 / 测试人员 | 排查一次运行，比较两个实验 | Langfuse 原生界面 |
| 运维体验者 | 查看真实指标，调整规则，配置邮箱 | Grafana 原生界面 |

## 信息架构

Portal 根路径直接显示质量保障旅程：顶部为产品与单智能体上下文、独立工作台入口；主体按顺序显示五阶段生命周期地图；下方为四组保障入口；顶部设置只处理非敏感地址与标识。规划中阶段没有链接和假操作按钮。能力支持状态与服务健康是两类独立信息。

信贷工作台根路径直接显示对话；左侧固定四项菜单：对话、Skills 能力库、模型服务、Mock 银行。新对话入口位于对话区域，配置更新后保留旧会话并创建新会话。小屏侧栏收起，执行事实面板移动到对话下方；核心任务不依赖悬停。

## Portal 交互契约

| 入口 | 目的地与用户下一步 | 不可用状态 |
|---|---|---|
| 执行追踪 | Langfuse 指定项目的 Trace 列表，继续查看详情 | 缺项目标识时提示设置；不生成假链接 |
| 数据集与评测 | Langfuse 数据集、实验与分数，按版本校验原生路由 | 未创建数据集时显示初始化未完成 |
| 运行指标 | Grafana 指定 UID 的运行仪表盘 | 未确认地址时显示尚未检查 |
| 运行告警 | 分别链接 Grafana 规则、Contact points | 不在 Portal 创建邮箱表单 |
| 打开信贷工作台 | 独立站点的新标签页，办理合成案例辅助分析 | 地址错误给出可修复提示 |

所有外链使用新标签页并带 `noopener noreferrer`，旁边说明原生工具名称。健康状态为尚未检查、检查中、可访问、不可访问、检查过期，并显示检查时间。页面可访问不等于链路可用：证据覆盖范围必须写明。Portal 不代理任意 URL 做健康探测；探测只使用启动配置允许的内部固定服务端点，认证不在浏览器绕过。配置自定义外部地址时可以保留“健康未验证”。

地址设置允许 HTTP（本地演示）和 HTTPS，拒绝脚本协议、带用户名/密码的 URL。只持久化公开 Base URL、项目 ID、数据集名与 dashboard UID；不接受 API Key、邮箱名单、SMTP 凭据。允许重置地址但不删除业务运行数据。

## 对话运行交互

1. 未配置模型：页面可打开，发送不可用，说明前往模型服务配置。
2. 选择合成案例并输入任务：提示工具结果来自 Mock 银行，输出只供辅助分析。
3. 提交后立即禁用重复发送；前端为此请求生成幂等键，服务端返回稳定的 runId。
4. 仅接收后端真实事件：Skill 文档加载、激活、工具开始、返回、异常、生成文本、终态。不存在的步骤不凭时间补齐。
5. 建议区显示结构化建议类别、依据、缺失材料、人工处理原因；原始文本是模型输出，不视为已校验的事实。
6. 流断开显示“连接中断，正在核实运行状态”，按 runId 重新查询；结果未知时明确显示“终态未知”，重试不会自动新建执行。
7. 成功、失败、需要人工处理分开显示。保守转交建议可属于技术完成，不等于技术失败；工具超时仍保留错误事件。
8. Trace 链接使用服务端真实 traceId；异步上报未确认时显示“追踪上报待确认”，不得用拼接 URL 宣称已入库。

可访问性：表单有明确标签；状态同时提供图标与文字；事件更新用节制的 live region；键盘能访问所有可用入口；灰显内容说明规划中但不占操作焦点。

## 其余三项菜单

**Skills 能力库：** 后端返回实际框架发现结果，列出名称、内容 SHA-256、加载结果、绑定的应用工具、原始 SKILL.md 与示例。发现、文档激活、工具执行是三种不同证据。发现不等于已经执行；绑定工具来自应用 manifest，不能误称 Core 原生字段。无 Skill 或加载失败显示错误，不填充静态成功卡片。

**模型服务：** OpenAI-compatible 是首轮候选；协议范围以 SDK 探针通过为准。API Key 用空密码输入框替换已有密钥，GET 只返回 `hasApiKey`。保存配置与实际测试分开；测试说明将发生真实调用和可能的费用，逐项验证文本、带参数工具调用及多 chunk 流式输出，记录失败原因、版本与时间。重开页面不回显任何密钥尾号。新会话采用新配置，旧会话继续使用不可变快照。

**Mock 银行：** 六个合成案例均显示来源标识、材料与接口场景、预期需要验证的行为。客户备注中的提示注入作为不可信数据展示，绝不执行。其中“征信超时”是实际工具适配层超时，不是前端播放错误动画。持续故障仅在显式演示模式开放，带恢复按钮与当前真实配置；重启默认关闭故障以免遗留演示状态。

## 主要旅程与失败路径

| 旅程 | 核验点 |
|---|---|
| 首次启动 → Portal → 工作台 → 模型服务 → 新对话 | 不配置模型也能打开站点，真实能力测试有独立结果 |
| 正常案例 → Skill → 银行工具 → 建议 → Trace | 所见事件能追溯到同一 runId 与 traceId |
| 超时案例 → 错误依据 → 保守转交 | 不把缺失征信判成通过，不声称完成真实审批 |
| Runner 两批运行 → Langfuse 原生比较 | 同数据、同规则、明确配置差异；执行失败与零分分开 |
| 显式启用规则 → 真实故障负载 → Firing → 恢复 | 验证 Grafana 状态时间线；邮件单独验收 |
